# Contributing

Contributions and bug reports are welcome.

1. Open an issue describing the problem or proposed change before large changes.
2. Keep changes focused and avoid adding dependencies without a clear need.
3. Run the syntax checks listed in [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md).
4. For changes to screen sharing or signaling, manually test both browser roles on the same local network.
5. Describe behavior changes and any manual testing in your pull request.

There is currently no automated test suite.
